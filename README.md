# 🎈 GAME-ShootTheBalloons

> **Status:** 🚧 Em construção

## 📖 Sobre

Este projeto é um jogo simples de atirar em balões, desenvolvido para praticar conceitos de interatividade e manipulação de eventos em um ambiente de jogo. O objetivo foi criar uma experiência de mira e pontuação utilizando JavaScript.

---

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** JavaScript
*   **Frontend:** HTML, CSS
*   **Biblioteca:** p5.js

---

## ✨ Principais Aprendizados

*   Implementação de lógica de detecção de clique em elementos gráficos.
*   Gerenciamento de pontuação e estados do jogo.
*   Criação de animações para balões e projéteis.
*   Desenvolvimento de uma interface de usuário simples para um jogo.
